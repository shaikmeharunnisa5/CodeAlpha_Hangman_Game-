# 🎮 Hangman Game

A simple and interactive **Hangman Game built using Python**. The player has to guess a randomly selected word one letter at a time. The player is allowed a maximum of **6 incorrect guesses**.

---

## 📌 Project Description

This project is a console-based Hangman game developed using Python.

At the beginning of the game, a word is randomly selected from a predefined list. The player must guess the word by entering one letter at a time.

If the guessed letter exists in the secret word, the letter is revealed in its correct position. If the guessed letter is incorrect, the number of incorrect guesses increases.

The game continues until the player either guesses the complete word or reaches the maximum limit of 6 incorrect guesses.

---

## ✨ Features

- 🎲 Randomly selects a word
- 🔤 Allows the player to guess one letter at a time
- 👀 Displays the current progress of the word
- ❌ Allows a maximum of 6 incorrect guesses
- 🔁 Prevents repeated guesses
- ✅ Displays a winning message when the word is guessed
- 😢 Displays a losing message when the maximum incorrect guesses are reached
- 🖥️ Runs directly in the Python terminal
- ✔️ Validates user input
